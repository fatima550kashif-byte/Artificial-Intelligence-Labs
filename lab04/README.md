# Lab 04: Linear & Multiple Linear Regression

## Overview
This lab explores predictive modeling using Linear Regression techniques on tabular datasets:
* **Simple Linear Regression**: Predicting employee salaries based on years of experience (`Salary_dataset.csv`).
* **Multiple Linear Regression**: Predicting property valuations using multiple structural and geographic features (`Housing_dataset.csv`).

## Objectives
* Perform data pre-processing, feature selection, and train-test splits using `scikit-learn`.
* Fit linear regression models to analyze single and multi-variable feature relationships.
* Evaluate model performance using Mean Absolute Error (MAE), Mean Squared Error (MSE), Root Mean Squared Error (RMSE), and $R^2$ Score.
* Visualize actual vs. predicted values and regression trendlines.

## Contents
* `Simple_Linear_Regression.ipynb`: Single-variable salary prediction model and evaluation.
* `Multiple_Linear_Regression.ipynb`: Multi-variable housing price prediction model.
* `README.md`: Lab overview and documentation.
