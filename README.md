# Introduction to AI Labs (AI-101L)
Lab work for Introduction to Artificial Intelligence (AI-101L).
Covers environment setup, Git and GitHub, web scraping, text and image features, regression, FastAPI, CNNs and MNIST digit recognition.
Each lab folder contains the notebook, dataset and results.
More labs are added as the course progresses.

| Lab-06 | FastAPI |

| Lab-08 | Digit Recognition on MNIST Dataset |
