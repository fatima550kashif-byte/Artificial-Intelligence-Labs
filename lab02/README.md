# Lab 02: Web Scraping & Feature Engineering

## Overview
This lab focuses on extracting e-commerce product data from the official **Sapphire Pakistan** website using web scraping techniques, followed by data cleaning, structuring, and feature engineering to prepare the dataset for machine learning models.

## Objectives
* Scrape product details (titles, prices, categories, availability, and descriptions) from Sapphire Pakistan.
* Clean raw text and handle missing values or non-standard formatting.
* Perform feature engineering (e.g., price normalization, category encoding, text attribute extraction).

## Contents
* `Lab_02_Sapphire_Scraping.ipynb`: Main notebook containing scraping scripts, data cleaning steps, and feature engineering logic.
* `README.md`: Overview and documentation for Lab 02.
